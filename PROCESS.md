# Project Coordination Process

## 1. Intake

New work is captured as a GitHub Issue with a clear description, owner, and expected outcome.

---

## 2. Prioritization

Tasks are prioritized based on:

- Impact to project goals  
- Urgency  
- Dependencies  
- Resource availability  

---

## 3. Execution

Each task must have:

- A clearly assigned owner  
- Defined next steps  
- Updated status  
- Target completion timeline  

---

## 4. Meetings

Recurring coordination meetings include:

- Agenda preparation  
- Review of open tasks  
- Identification of blockers  
- Assignment of action items  
- Summary of decisions  

---

## 5. Documentation

Project documentation is updated when:

- Decisions are made  
- Processes change  
- New contributors join  
- Risks are identified  

---

## 6. Follow-Through

All action items are tracked until completion.  
Blockers are escalated when they impact delivery timelines or require additional support.

---

## 7. Communication

Updates are:

- Clear  
- Concise  
- Action-oriented  

Each update answers:

- What changed  
- What is blocked  
- What is next  
- Who owns the next step
